# 🚨 SOS 360 - Emergency Alert App

SOS 360 is a Kotlin-powered Android application designed to provide quick emergency alerts with live location sharing to trusted contacts. Whether in danger, distress, or need of urgent help, SOS 360 allows users to notify their circle or services within seconds.

---

## 📱 Features

- 📍 One-tap SOS alert with live GPS location
- 👨‍👩‍👧‍👦 Add and manage emergency contacts
- 🔔 Real-time notifications via SMS/Email/API
- 🗣️ Optional voice message or custom alert
- 🌐 Offline fallback functionality (if network drops)
- 🔒 End-to-end encryption and user data protection

---

## 🛠️ Tech Stack

- **Language**: Kotlin
- **Platform**: Android (Jetpack, Android Studio)
- **Location**: Google Maps API / FusedLocationProvider
- **Database**: Room / Firebase (Optional)
- **Notification**: SMSManager / Push API
- **Architecture**: MVVM with LiveData & Coroutines
